# Project 01: Network Traffic Analysis

## Project Status
Analysis completed using a simulated 15-record network traffic dataset.

## Objective
To practise analysing simulated network traffic with Python and documenting the findings.

## Investigation Goals
- Analyse a simulated network traffic dataset using Python.
- Identify common network protocols, including TCP, UDP, and ARP.
- Examine source and destination IP addresses.
- Summarise protocol and IP address activity from the available dataset.
- Identify unusual or potentially suspicious traffic patterns.
- Document findings in a clear investigation report.

## Tools
- Python
- Windows
- PowerShell

## Project Structure
- Scripts: Python scripts used for traffic analysis.
- Data: Safe sample data used during the investigation.
- Evidence: Screenshots and supporting evidence.
- Reports: Investigation findings and technical documentation.

## Expected Deliverables
1. Python script for analysing the simulated traffic dataset.
2. Simulated sample traffic data.
3. Protocol and source and destination IP summaries.
4. Analysis output screenshot and protocol distribution chart.
5. Investigation report documenting findings and limitations.

## Safety and Scope
All testing will be conducted on authorised traffic or safe sample data. Private network captures and sensitive information will not be published.

## Results
The Python analysis summarised 15 simulated traffic records by protocol and source and destination IP address. See the investigation report for the findings and limitations.

## Lessons Learned
A small Python script can summarise protocol and IP address activity from a CSV dataset. Simulated data is useful for practice, but it cannot show the full detail of a live packet capture or confirm malicious activity
